# Key findings (captured snapshot: 2026-11-11)

- Source denominator: 128,053 active technology postings.
- Skill rows: 76.
- Top skill: Python (42,872; 33.48% of denominator).
- Top-quartile demand threshold: 19 skills (top 25% of the 76 displayed skill rows).
- Top-quartile coverage: 2 core/direct; 13 related/elective; 4 no explicit match.
- Weighted alignment index: 44.7% (rubric-based, not an official metric).

## Interpretation

The top-demand skill group is not fully described by traditional core subject labels alone. The reference curriculum offers relevant foundations through programming, databases, operating systems, software engineering and optional machine-learning/cloud specialisations. At the same time, some current frameworks and newer AI application terms are not explicitly named in the 2022 reference curriculum. This suggests an agenda for reviewing electives, laboratories and projects, rather than proving that institutions fail to teach these topics.

## Important qualification

These findings compare job-posting mentions with a national model curriculum. They do not measure student competence, hiring outcomes, employer satisfaction or actual placement probability.
